# Клёв — PWA

Готовый фронтенд без сборщика: можно разместить на любом статическом хостинге.

## Запуск локально

Service Worker и Geolocation не работают корректно через `file://`, поэтому поднимите простой HTTP-сервер:

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`.

## Что внутри

- ручной выбор населённого пункта с подсказками через Open-Meteo Geocoding API;
- определение координат через `navigator.geolocation`;
- почасовая погода через Open-Meteo;
- детерминированный солунарный слой без ML;
- погодный слой по правилам из приложенной методологии;
- процент сейчас;
- лучшие двухчасовые слоты;
- график активности по часам;
- PWA manifest + Service Worker + offline app shell.

## Источники данных

Open-Meteo используется для геокодинга и погоды. Расчёт солунарных событий выполняется в браузере.

## Важные ограничения

1. Коэффициенты модели повторяют экспертные диапазоны из методологии и не являются обученной моделью.
2. Лунные эфемериды в этой версии рассчитаны приближённым детерминированным алгоритмом; для production можно заменить их на библиотеку/сервис эфемерид с более высокой точностью.
3. Геолокация при нажатии кнопки использует координаты устройства; обратный поиск названия места намеренно не завязан на публичный Nominatim autocomplete.
4. Для крупного публичного продукта рекомендуется вынести внешние API через свой backend/proxy и добавить кэширование.

## Атрибуция

В интерфейсе указаны Open-Meteo как источники погоды и геокодинга.
